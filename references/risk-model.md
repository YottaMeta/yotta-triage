# 元鉴风险分级模型（risk-model）

元鉴的风险分级是**静态线索提示**：对每个文件的静态指标加权求和，映射到
info / low / medium / high / critical 五级。**不代表样本确定恶意**；
最终判定需人工 / 动态分析 / 情报交叉验证（与元情 yotta-intel 联动时亦如此）。

## 1. 指标加权

| 指标 | 分值 | 说明 |
|---|---|---|
| 整体熵 ≥ 7.5 | +3 | 疑似强加密 / 加壳 / 压缩 |
| 整体熵 6.5-7.5 | +2 | 偏高，常见于加密 / 压缩载荷 |
| 整体熵 5.5-6.5 | +1 | 轻度偏高 |
| 疑似加壳区段（UPX / packed 等） | +3 | 强加壳线索 |
| PE 可写可执行区段（RWX） | +2 | 可疑内存布局 |
| PE 高熵区段（≥7.0） | +1 | 区段级加密 / 压缩 |
| ELF RWE 段（PT_LOAD + RWX） | +3 | 可疑内存布局 |
| ELF 可写可执行节 | +2 | 可疑 |
| 可疑命令关键字（每条类型，封顶 3） | +2/条 | powershell -enc / certutil / bitsadmin 等 |
| 可执行文件内嵌 URL | +1 | 下载 / 回连线索 |
| 长 base64 块 | +1 | 疑似编码载荷 |

## 2. 分级映射

| 评分 | 级别 | 退出码 |
|---|---|---|
| 0 | info | 0 |
| 1-2 | low | 0 |
| 3-4 | medium | 1 |
| 5-6 | high | 2 |
| ≥7 | critical | 3 |

- 报告取所有文件的最高级别作为 summary.max_risk，CLI 退出码与之对应。
- 用法 / 读取错误 → 退出码 4。

## 3. 判定纪律

- 只提示，不执行：工具不反混淆、不解包、不动态运行样本。
- 不给定性：任何风险级别都是「可疑线索」，不写「这是恶意软件」结论。
- 建议路径：元鉴静态初筛 → 元情（yotta-intel）整理 IOC → 人工 / 沙箱 / 情报平台交叉验证。

## 4. 与元情（yotta-intel）衔接

- 元鉴 --ioc-only 输出 JSON 数组：{type, value, file}，type ∈ hash / url / domain / ipv4 / email。
- 元情可直接读取该 JSON 做进一步归一 / defang / 去重 / 转 STIX，或人工导入情报平台。
